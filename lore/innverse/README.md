# lore/innverse/

Setting that should stay true in every Innverse game using this kit.

This folder is **empty on purpose**. Do not invent a gazetteer here. Do not put one game’s city, war, cast, or mystery here (`lore/campaign/`).

## How to use this folder

If a fact is already on a page in this vault, use the vault.

If a setting fact is **not** in the vault (a continent, a widespread institution, how a species is usually treated, a well-known city), look it up on existing public Wandering Inn wikis and summaries.

If the wiki and this vault disagree, **this vault wins**.

Do not import novel plot or novel characters into a game unless the narrator has already put them in this clone.

Do not treat a wiki anecdote as new System law. System law lives in `frameworks/`.
