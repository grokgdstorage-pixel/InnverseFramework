# Places

Copy this file to `lore/campaign/places.md` after a clone.

Rooms the table actually uses. A cold read uses this so a street is not invented twice. A human uses it to remember where play is standing.

Not a gazetteer of the Innverse. Add a card when the thread goes there, or is about to. If a name must exist off-camera, one line under **Not in play**. Do not write a travel guide.

Blank or `unknown` = unknown. Do not invent.

In Obsidian, fold the unused copy-card. Do not delete folded text.

---

## Not in play

Names that exist and have not been used. One line each. Example: Pallass exists; we have not gone. Delete the example.

---

## Card (copy)

**Name:** What it is called.

**What it is:** Inn, street, chamber, ship, camp, hall. One line.

**Where:** Region or parent place, if that matters. Blank if this card *is* the parent.

**Who holds it:** Person or faction. Link if a page exists. Default: `TBD`.

**How it feels:** What a body notices walking in. Two to six lines. Not poetry for its own sake.

**What play has done here:** Only what the thread already did. Blank if new.

**Additional:** A rule of the house, a door that matters, a danger that is true. Leave blank if nothing extra is true.
