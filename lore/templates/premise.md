# Premise

Copy this file to `lore/campaign/premise.md` after a clone. One premise per game.

A human uses this as the box lid. A cold read uses it so the first post does not invent a different game.

This is not a novel. This is not `lore/innverse/`. Facts that would still be true in another Innverse RP do not belong here.

Blank or `unknown` = unknown. Do not invent.

---

## At a glance

**Where it opens:** Place and room the first posts occupy.

**When it opens:** Season, year-in-setting, or “unestablished.” Real-world start date if useful.

**Who is on camera:** Play characters, one line each. Link their folder when it exists. Default link: `TBD`.

**What this game is about:** One sentence. Arrival, war, an inn, a job. Not a pitch paragraph.

---

## Table law

Tone and limits that are law for this clone. Pace. Romance. Violence. What the table will not write.

System house rules for this table live in `reference/campaign/`. Point at that file. Do not reprint kit law here.

---

## What this clone is not

Canon people and plot from the novels. Cast recycled from another vault, if that is off limits. Anything else this table refuses to be.

---

## Open

Questions the table has not answered. Leave as `TBD` so a later scan can find them.

---

## Additional

Only what is unique to this game and not already above. Leave blank if nothing extra is true.
