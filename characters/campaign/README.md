# characters/campaign/

Empty in the template. After a clone, this is the cast of that game.

How to add someone
1. Copy characters/templates/pc.md or npc.md
2. Paste it here as a new file named for the character
3. Fill the sheet
4. Do not edit the file in characters/templates/

One file per person. Keep mechanical facts (Class, level, Skills) in sync with play.
