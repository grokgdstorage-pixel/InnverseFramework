# Character templates

These folders are **blanks**. Copy one into `characters/campaign/<slug>/` when a real person exists.

In this repo the files live under `templates/`. That is correct. After a copy, the copy is a living person. If a work order makes that copy, tell Clerk to point the file label at the new folder. You do not need to edit labels by hand unless you are copying without Clerk.

Blank heading = unknown. Do not invent.

## Two shapes

- `_person/` — Player and Important. Same files. Density changes.
- `_background/` — one `profile.md`. One named person per folder. Promote when they recur or the player leans in.

## First read

`profile.md` → `mind.md` → `relationships.md` → `record.md`. Then a Grand Design file (`the-system.md`, `classes.md`, `skills.md`, `leveling.md`) if a ruling might open. `magic.md` only if it exists.

On `mind.md`: read Personality and How their mind operates first. Then only the labeled section the scene needs.

## Grok packet

Not a finished forum post unless asked.

1. Tier
2. What they want this scene
3. What they will not do
4. Whether a System or spellcraft file should open
5. A beat or post angle. Off-screen events are the narrator.
