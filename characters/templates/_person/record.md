# Record

Facts the Grand Design has **already** put on this person.

How to *offer* a new Class, Skill, step, or Condition lives in `the-system.md`, `classes.md`, `skills.md`, `leveling.md`, and `conditions.md`. Do not reprint those files. Do not invent level, Skills, or a mark.

Blank or `unknown` = unknown.

Read this page when a ruling or a scene needs what they **hold**. Dated gain-by-gain log belongs in `history-system.md`. How they think belongs in `mind.md`. Bound Spells belong in `magic.md`.

---

## At a glance

Class and Level only. One line per Class they still have. Current name after consolidation. No Skills here.

- [Class] — Level
- [Class] — Level

---

## Conditions and other marks

Standing System marks that are not a Class or a Skill. Name — what it does in play. Or **None.** How to offer or lift one lives in `conditions.md`.

---

## Stored and refused

**Stored:** Lost Class or Skill that can come back if the Class is restored. Name + what was stored.

**Refused:** Offers that expired. Deeds that led to them still count. Do not list the dead offer as something they hold.

**None** if both are empty.

---

## Classes

One block per Class they still have. Copy the block. Delete unused blocks. Name the Class as it currently is (after consolidation), not every ancestor name.

Paste each Skill card **under that Class**, below Additional. Do not dump Skills in a pile at the bottom of the page.

In Obsidian, fold the **Skills** heading under each Class so a human sees Class + Level + Additional first. Do not delete folded text. A cold read of the `.md` file must still contain every card.

### Class (copy)

**Class:** Bracket name as it stands now.

**Level:** Number if known. `unknown` if not.

**Additional:** Only what is unique to this Class on this person. A refused consolidation. A Skill they will not use. Leave blank if nothing extra is true.

#### Skills

Every Skill they have from this Class. One Skill card each. Current name if it grew or was renamed. No name-only list.

##### Skill (copy)

**Name:** Bracket name as it stands now.

**Activity:** Passive / Active / Toggle / `unknown`.

**Function:** What it appears to do in play. One to three lines. Not a wiki essay. Not a new Skill.

**Origin:** Class pool it came from. Obtained, learned, or grown. If it did not come from the Class block above, say which pool and why it sits here.
