# frameworks/

Innverse system documents shared by every game.

## Grand Design
The System lives in grand-design/.
That folder is the parent. Classes, Skills, and levels are products of the System, not separate grant-engines.

## Magic
Magic sits beside the System in magic/.
It is related. It is not a fourth Grand Design output.

## How to use
- Read grand-design/the-system.md before generating a Class, Skill, or level.
- Then read only the child file for that product.
- Prefer process and examples over catalogs.
- A clone should not rewrite these for flavor. Campaign variants go in reference/campaign/.
