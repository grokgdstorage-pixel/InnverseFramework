# frameworks/

Innverse system documents shared by every game.

## Grand Design
The System lives in grand-design/.
That folder is the parent. Classes, Skills, levels, and Conditions are products of the System, not separate grant-engines.

## Magic
Magic sits beside the System in magic/.
It is related. It is not a fourth Grand Design output.

Mana-path teaching (learn / rebuild / invent a spell) lives in magic/spellcraft.md.

## How to use
- Read grand-design/the-system.md before generating a Class, Skill, level, or Condition.
- Then read only the child file for that product (`classes.md`, `skills.md`, `leveling.md`, `conditions.md`).
- Prefer process and examples over catalogs.
- A clone should not rewrite these for flavor. Short exceptions go on that clone’s lore/campaign/premise.md under Table law.
