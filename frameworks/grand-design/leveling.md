# Leveling

## Scope

Application manual for **one product: a level**.

Read `the-system.md` first. If the Class name itself might change, read `classes.md`. If the question is what Skill they receive, read `skills.md`.

This file answers:

- when a level fires
- when the System stays silent
- capstone as a *level event* (every ten; harder step; rarer Skill slot)
- how fast someone can step under counter-leveling
- what a level grants in this kit
- how to treat height after consolidation or demotion

This file does not answer:

- Class identity (`classes.md`)
- which Skill to pick (`skills.md`)
- when they *hear* the announcement (parent §5: unconscious / usual sleep; awake only while counter-leveling)
- Conditions (`conditions.md`). System colors: parked.
- magic
- XP or a stat block

## How to use

If you have not walked Watch → Judge → Product on `the-system.md`, stop and do that first.

Open this file when the product in play might be a level: a step, silence instead of a step, a capstone step, a counter-leveling step, or a new height after fold or demotion.

### Output

Grok ruling packet, not forum text.

Return:

1. Level outcome options: silence / one level / more than one level / capstone step / counter-leveling step / height after fold or demotion. Do not pick one in silence.
2. Which Class the step would sit on
3. A short reason on each option (deed, path, accumulation, exertion, cost, reach)
4. Whether `skills.md` should open (almost always yes if a step lands) and whether `classes.md` should open

Default stance: always give the narrator options, with a short reason for each. Include silence as an option when the life might not have stepped. When a step is honest, include both “Skill obtain” and “Skill grow” as *pointers* to `skills.md`. Do not pick the Skill here.

When the step would be a capstone, say so. Include wait as an option if they have not truly arrived. Point at `classes.md` and `skills.md` for the re-evaluation, not only at +10.

Narrator finalizes. Grok proposes.

### Stops

- No XP table.
- No stat block.
- No Skill list and no List A / List B in this file. That is `skills.md`.
- No Class rename in this file.
- Do not invent a level number after consolidation or demotion. Propose heights with reasons. Narrator picks.
- Do not copy the announcement rule except as a pointer to parent §5.
- Example numbers in this file are illustrations (Level 8, Level 10). Do not require them.
- If `skills.md` is missing, say “step / no step” and stop. Do not invent Skills.
- System colors: parked.

## What a level is

A level marks that this Class has grown enough to step.

In this kit the main gifts of a level are the **fact of the level** and whatever Skill product `skills.md` then offers (obtain, grow, sometimes several small, sometimes none). There is no default stat block.

Higher levels are harder. Near a capstone they are harder still. Passion and challenge move someone. Empty years do not.

## When a level fires

The parent already decided a mark might be due. This file asks: is that mark a *step* in a Class?

A step is honest when the life in that Class has actually grown: refinement, practice, dedication, impact, accumulation, reach, exertion — enough that the current height no longer fits how they inhabit the role.

Silence is honest when they kept the same height: same inner story, no sharper path, no real cost. Time held is not a step.

Do not fire a level because a player asked. Do not refuse a level only because they already have another Class. Time and drive limit how many paths can move; they are not a fine.

If silence vs one level vs more than one is unclear, list the readings. Default: options, not a jump.

**More than one level** is earned when what they displayed sits *beyond* the current height of that Class: deeds, knowledge, expertise, exertion past what Y level in that path should hold.

The common route is high-stakes struggle (most often crushing combat): live, push past the limit, or die.

A second route is a **breakthrough in the same Class**: a line of inquiry or a new way of inhabiting the path that meaningfully expands what they understand. Not a small improvement. The Class itself has opened.

A third route is a high-quality mind or body entering an **adjacent** path: wisdom, intellect, cunning, knowledge, physical aptitude already in place. The System can read “this is past X Class at Y height” and either hand several levels in that Class, or keep the number low and place them in a *higher hierarchy* Class instead (`classes.md` owns that name). That reading is rare, in the same band as learned Skills. It needs real potential and a path close enough that the old capability transfers.

Do not hand more than one level without an honest exertion or a display beyond what that Class-at-that-height usually holds. A good afternoon is not enough. Do not refuse more than one level only because the scene was not a battle.

Ordinary scenes that are not past that height: default menu is silence or +1. More than one level is not on that menu.

## Silence

Silence is a product. Include it when it might be true.

A [Guard] who held the same gate with the same mind for a month does not step. They may still receive a Skill-only mark (`skills.md`) if practice sharpened one capability without the Class height changing. This file only says: no level.

## Capstone (level event)

Every ten levels in a Class (10, 20, 30, 40, 50, …) is a capstone *step*. It is a milestone in that Class, not just the next number.

A capstone is **significantly** harder than an ordinary step. It needs true progress and understanding in the path — the role inhabited more fully, not another month of the same height. Waiting until the number is due is not enough. If they have not actually arrived, the honest option is to wait.

Outside extreme circumstances (crushing counter-leveling, a defining tragedy, narrator override), a capstone is also where the **greatest rewards** of that stretch tend to sit: rarer Skill slot, more weight, more chance that a held Skill has outgrown its form. Rarer is not automatic-maximum and not an automatic pass of the Skill ceiling. `skills.md` owns the pick.

**Re-evaluation.** When a capstone is in play, do not only ask “+10 or wait.” Open a deeper look:

- Is the Class name still the truth, or should `classes.md` speak (flavor, hierarchy step, specialize, fold)?
- Which held Skills no longer fit (`skills.md`: grow vs obtain vs several)?
- What deeds and mindset since the last capstone actually changed the path?

That review is a **wide** options list plus reasons: possible name reads, possible Skill obtains, possible grows, possible waits. Oversupply is fine. The narrator cuts. Do not lock a rename or a Skill in silence.

How hard a given capstone is remains options to the narrator. High capstones (especially 50) are defining weight, not a formula.

After Level 50 the novels often hand a Skill more often. Exact rate is parked. Do not flood low-level characters with that rumor. When someone is past 50, include “Skill with this level” as a strong option in the `skills.md` pointer. Narrator still picks.

## Counter-leveling (rate only)

Voice is parent §5: heard **while awake**, lower-level side.

Canon shape: *a lower-level foe, growing exponentially against impossible odds.*

This is David and Goliath, not “anyone whose life was at risk.” Need all of:

- A real mismatch — they should not be able to win
- Dire need — they cannot simply walk away
- They are in over their depth
- Enough innate quality, luck, or help that they *tread water* instead of drowning at once

If they only hide, freeze, or die in the first moment, it is not this. If the foe is merely scary but matched, it is ordinary struggle, maybe +1 or +2 under the beyond-height rule, not counter-leveling.

This file owns **rate**. While those odds hold, they can step much faster than ordinary life. They still have to act in the struggle. Standing nearby is not enough. A known tactic is to send the weaker side into those odds on purpose so the *survivors* come back taller. That costs lives. It is not a farm.

The mismatch can be a person, a war, a plague, a thing they are not built to face. Combat is the common picture. It is not the only one.

How many levels a given stretch is worth: a **wide** menu for the narrator. Do not write a per-exchange number. A short impossible clash can still be more than one step. A week under a siege can be more still. An ordinary scare is not this.

When they can meet the threat, or the threat ends, the fast rate ends. Ordinary silence returns. They do not keep counter-leveling after they have grown enough to stand even.

Usual pace in the world is days to weeks under the odds. Minutes-and-consolidation is the sharp end, not the average night.

## What a level grants

Always: the new height in that Class.

Usually also: open `skills.md` for obtain-new and/or grow-held (and the other Skill options). This file does not pick the Skill.

Sometimes also: open `classes.md` if the name itself should move. A level does not automatically rename the Class.

Never by default: a stat block.

## Height after fold or demotion

Consolidation and demotion change identity in `classes.md`. This file only speaks to the number.

Do not calculate one official total. Give the narrator a **range of possible heights**, each with a short reason.

Always give a **wide** list. Do not return one number. Include at least these looks, each with a short reason:

- average of the folded heights
- median of the folded heights
- as high as the highest folded Class
- as low as the lowest folded Class
- weighted toward the path that actually survived
- hierarchy cut — a large jump drops the number (Level 15 [Leader] → [King] is usually a **very low** [King], not 15)
- a generous high option the narrator can reject
- a harsh low option the narrator can reject

The same idea applies when a single Class steps up a great deal in hierarchy, not only when several names fold.

There is no hard formula and no hard cap. One average is not the answer. Ask the narrator. Oversupply of options is better than a single guess. The narrator cuts.

Stored Classes keep their stored height on the record. Partial restore can return a lower height than was stored.

## Examples

Not a catalog.

**Packet shape, ordinary.** Level 8 [Guard], real month on the same gate, no display past that height.
Options:
- Silence — same height, same mind. Skill-only if anything (`skills.md`).
- +1 — only if the path actually sharpened.
Not on this menu: +2, capstone, [King].
Each option has a reason. Narrator picks.

**Packet shape, capstone.** Level 9 [Guard], real progress in how they hold the post.
Options:
- Wait — they have not arrived at the milestone.
- Capstone step to 10 — harder gate, greater ordinary reward than 8→9. Then re-evaluate name (`classes.md`) and held Skills (`skills.md`).
Not on this menu: +10 levels, automatic ceiling Skill, forced rename.

**Silence.** Same gate, same mind, a month. No level. Skill-only is `skills.md` if anything.

**One step.** The [Guard] path is actually sharper than last mark. Level 8 → 9. Then `skills.md` for obtain and/or grow.

**Player want.** They ask to hit 20 after a quiet week. Silence or a small in-path option. Not +10.

**Capstone.** Level 9 [Guard]. If they only held the gate the same way, wait. If they now understand the post in a way Level 9 does not cover, the Level 10 capstone is honest — harder, milestone, greater reward than 8→9. Then re-evaluate: is [Guard] still the name? Which gate Skills have outgrown their form? `classes.md` and `skills.md` get that look. Not an automatic ceiling Skill. Not a forced rename.

**Counter-leveling.** A Level 12 stands against a foe that should end them, cannot leave, and stays in the fight long enough to tread water. Wide menu: +1, more than one, still silence if they only hid. Voice is awake (parent). Not a matched scare. Not standing nearby. Rate ends when they can stand even.

**More than one, struggle.** They survive what should have ended a Level 8 [Guard]. Options: +1, more than one, or still silence if they only hid.

**More than one, breakthrough.** They open a real new line in the same Class — the path is larger than it was, not just practiced. Options: +1 or more than one. Not a small improvement.

**More than one, aptitude.** A practiced mind starts an adjacent path and performs past a beginner’s height. Options: several levels in the modest Class, or a higher-hierarchy Class at low level (`classes.md`). Rare. Not a good afternoon. Not automatic.

**More than one, off-screen.** A season of real work not played blow by blow. Options for how many steps. Do not dump ten levels because time passed.

**Fold.** Three Classes become one path. `classes.md` names it. This file offers a *range* of heights (average, median, weight the surviving path, cut the number if hierarchy jumped). Each option has a reason. Narrator picks. A Level 15 [Leader] becoming [King] is usually a very low [King], not [King] 15.

**Hierarchy jump, one Class.** Same idea without a fold. The name went up a great deal. Offer a low number for the new height. Not the old number wearing a crown.

**Demotion.** A [King] falls. Stored height stays on the record. Active Class is lower. This file offers a lower number for the living role. Partial reclaim later can return only part of the stored height.

**Multi-Class.** They lived the [Potter] path, not the [Soldier] path. Only [Potter] is in play for a step.

## Design notes

- Level = investment / height in a Class. Not a stat block.
- Capstone = milestone. Significantly harder. Needs true progress and understanding. Greatest ordinary rewards of that stretch. Triggers a re-evaluation of Class name, held Skills, and deeds. Pick stays in the other children.
- Counter-leveling is mismatch + dire need + treading water. Not any life-or-death. Voice stays in the parent. Rate ends when they can stand even.
- Oversupply of options is fine. Narrator cuts.
- Always options plus reasons. Silence is an option.
- Post-50 Skill frequency is parked as a rate. Do not use it below 50.
- Fold and demotion heights are a range of options (average, median, surviving path, hierarchy cut). Narrator picks. No formula.
- A large hierarchy jump (Level 15 [Leader] → [King]) usually lands at a very low number in the new name.
