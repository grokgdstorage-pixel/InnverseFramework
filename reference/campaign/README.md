# reference/campaign/

Empty in the template. After a clone, this folder is the house-rules drawer for that game.

Put here
- table-specific exceptions to frameworks/
- posting exceptions
- a short decision-log.md for this game only

Do not put
- Grand Design rewrites meant for every future game (those go back to the template, on purpose)
- session posts (sessions/)
- character sheets (characters/campaign/)

Starter file to create after cloning: decision-log.md
Format: date, decision, why, which document it affects, campaign-only or proposed for the template.
